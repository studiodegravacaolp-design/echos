# MASTER ID REGISTRY

## Introdução

Este documento é a única fonte oficial para todos os identificadores do Projeto AETHERIS. Nenhum identificador pode ser utilizado em qualquer documento oficial sem estar previamente registrado neste Registro Mestre.

## Regras Gerais

- **Fonte única da verdade** para IDs do projeto.
- **IDs nunca são reutilizados.** Uma vez atribuído, um ID não pode ser usado novamente, mesmo que o item original seja descontinuado.
- **IDs nunca mudam.** A identificação de uma entidade é permanente e imutável.
- **IDs aposentados permanecem registrados.** Entidades descontinuadas mantêm seu registro com status apropriado.
- **Todo documento oficial deverá utilizar apenas IDs registrados** neste documento.

## Regras de Registro

1. Nenhum ID pode ser criado em outro documento antes de ser registrado neste Registro Mestre.
2. Caso um ID seja descontinuado, ele permanece listado com o status **APOSENTADO**.
3. É terminantemente proibido reutilizar um identificador, mesmo que o destino original não exista mais.
4. O status de um ID pode ser:
   - **ATIVO** — atualmente em uso no projeto.
   - **APOSENTADO** — descontinuado, mas mantido para referência histórica.
5. Qualquer alteração neste documento deve ser registrada no Histórico de Versão.
