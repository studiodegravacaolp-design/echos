# SYS-GRIMORIO-MIDGAME — Grimório de Progressão — Ato 3
**Versão:** 1.0.0  
**Status:** Consolidado  
**Classificação:** Sistema de Habilidades — Mid Game (Níveis 21–35)

---

## 1. Propósito

Este documento estabelece o registro oficial das habilidades do Mid Game (Níveis 21–35, Ato 3 — Diretório de Brenhold). Nenhuma mecânica nova é introduzida; apenas consolidação das regras operacionais estáveis vigentes sob o regime de Vácuo Acústico e Asfixia Rúnica de Brenhold.

---

## 2. Habilidades do Ato 3 — SYS-HABILIDADES-A3 (Níveis 21–35)

As habilidades abaixo são concedidas ou desbloqueadas ao personagem durante o Ato 3, operando sob as restrições acústicas e rúnicas do Diretório de Brenhold. Todas as habilidades seguem a **Regra Antivazamento R3 Reminscente** (Seção 2.4).

### 2.1 SKL-NEU-021 — Fricção Performativa

| Campo               | Valor                        |
|---------------------|------------------------------|
| **ID**              | SKL-NEU-021                  |
| **Nome**            | Fricção Performativa         |
| **Tipo**            | Neutro (Terra)               |
| **Dano Base**       | 94 (Terra)                   |
| **Custo**           | 20 de Stamina                |
| **Alcance**         | Corpo a corpo (2 m)          |
| **Tempo de Conjuração** | 0,8 segundo                |
| **Recarga (Cooldown)** | 3 turnos (9 segundos)      |
| **Deslocamento na Balança (Delta_M)** | **0** (estável) |
| **Descrição Operacional** | Golpe de fricção que gera vibração sônica no solo, desestabilizando o terreno ao redor do alvo. A ressonância mecânica não altera a Balança. |
| **Efeitos Visuais** | Ondulações de poeira e detritos no solo, distorção de ar por vibração mecânica. Proibida qualquer emissão cromática Ember ou Dourado Prismathico. Visual puramente termodinâmico mecânico e acromático. |
| **Regras**          | Delta_M = 0 fixo. Dano reduzido por armadura física. Pode causar tropeço (chance 15%) em alvos com menos de 50% de Stamina. |

### 2.2 SKL-NEU-022 — Harmônica de Contrapeso

| Campo               | Valor                        |
|---------------------|------------------------------|
| **ID**              | SKL-NEU-022                  |
| **Nome**            | Harmônica de Contrapeso      |
| **Tipo**            | Neutro (Físico — Passiva)    |
| **Dano Base**       | N/A (Passiva)                |
| **Custo**           | Nenhum                       |
| **Alcance**         | N/A (Autobuff)               |
| **Tempo de Conjuração** | N/A (Passiva)              |
| **Recarga (Cooldown)** | N/A (Passiva)              |
| **Deslocamento na Balança (Delta_M)** | **0** (estável) |
| **Descrição Operacional** | Passiva física que converte qualquer debuff de cooldown gerado por silêncio em **+15% de Velocidade de Ataque Cinético** durante a duração do efeito de silêncio. A conversão é automática e não consome recursos. |
| **Efeitos Visuais** | Leve cintilação acromática nas juntas do traje quando ativada. Sem emissão cromática. Visual puramente termodinâmico mecânico e acromático. |

### 2.3 SKL-PAT-021 — Estouro de Frequência

| Campo               | Valor                        |
|---------------------|------------------------------|
| **ID**              | SKL-PAT-021                  |
| **Nome**            | Estouro de Frequência        |
| **Tipo**            | Patrono (Fogo-Cinético)      |
| **Dano Base**       | Dano de Fogo-Cinético        |
| **Custo**           | 30 de Stamina / 15 de Mana   |
| **Alcance**         | 6 m (explosão direcionada)   |
| **Tempo de Conjuração** | 0,5 segundo                |
| **Recarga (Cooldown)** | 4 turnos (12 segundos)     |

| **Efeitos Visuais** | Jato de vapor pressurizado acromático, distorção de ar por calor intenso, ruído mecânico de escape. Proibida qualquer emissão cromática Ember ou Dourado Prismathico. Visual puramente termodinâmico mecânico e acromático. |
| **Regras**          | Delta_M = +15 fixo. Remove Silêncio do herói no momento da ativação. O dano é do tipo Fogo-Cinético (sofre redução parcial por armadura física e resistência elemental). |

### 2.4 Regra Antivazamento R3 Reminscente

**Proibição absoluta — VFX e Cromática para Habilidades do Ato 3:**

É **rigorosamente proibida** a exibição de qualquer cor associada às marcas **Ember** (vermelho alaranjado intenso, hex #E25822 e adjacências) ou **Dourado Prismathico** (dourado metálico cintilante, hex #C9A96E e adjacências) em qualquer habilidade do Mid Game (Níveis 21–35).

**Diretrizes de expressão visual obrigatórias:**

| Polo da Habilidade | Expressão Visual Permitida                                                                 |
|--------------------|--------------------------------------------------------------------------------------------|
| **Positivo** (Patrono / Fogo-Cinético / Calor) | Reações termodinâmicas físicas **opacas**: vapor superaquecido pressurizado, distorção de ar por calor, ejeção de vapor acromático, ruído mecânico de escape. |
| **Neutro** (Terra / Físico) | Vibração mecânica e ressonância sônica: ondulações de poeira, detritos, distorção de ar por vibração, sem emissão cromática. |
| **Passiva** (Físico) | Cintilação acromática nas juntas do traje, sem emissão de luz colorida. |

O visual permanece **puramente termodinâmico mecânico e acromático** em todas as habilidades do Ato 3.

## 3. Comportamento Operacional das Habilidades do Ato 3

| Requisito                          | Especificação                                                                 |
|------------------------------------|-------------------------------------------------------------------------------|
| **Dano Base Mínimo**               | 1.3x o dano base das habilidades do Ato 2 equivalentes.                      |
| **Deslocamento na Balança**        | Delta_M entre 0 e ±15, conforme o tipo.                                      |
| **Custo de Estafa (se canalizado)**| 20–30 unidades por uso.                                                      |
| **Recarga Mínima**                 | 3 turnos (9 segundos) para Neutras; 4 turnos (12 segundos) para Patrono.     |
| **Efeito Adicional Obrigatório**   | Habilidades Neutras podem aplicar efeitos de estado mecânicos (Tropeço, Lentidão Física). Habilidades Patrono devem interagir com o sistema de Silêncio de Brenhold. |
