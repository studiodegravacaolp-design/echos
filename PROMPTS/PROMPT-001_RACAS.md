# Objetivo

Estabelecer um Prompt Mestre oficial para a geração de conceitos visuais das raças do universo AETHERIS.

Este documento define as diretrizes necessárias para que qualquer Inteligência Artificial ou artista produza concepts consistentes com a identidade visual oficial do projeto.

Seu objetivo não é criar uma raça específica do zero, mas fornecer um padrão reutilizável que aplique o "DNA Visual de AETHERIS" a qualquer descrição de raça fornecida.

---

# Escopo

Este documento aplica-se exclusivamente à geração de Concept Art das raças do Projeto AETHERIS.

Inclui:
- Concepts de corpo inteiro (full-body shot);
- Estudos de silhueta única e reconhecível;
- Estudos anatômicos e de proporção (base para sprites 2D HD);
- Estudos de texturas de pele, escamas, metal e tecido (estilo Hand Painted/Diablo IV);
- Estudos de vestimentas básicas e culturais;
- Iluminação atmosférica e mágica integrada.

Não contempla:
- Armaduras de combate complexas (ver PROMPT-002);
- Armas (ver PROMPT-003);
- Arquitetura (ver PROMPT-007);
- Sprites finais ou Portraits (ver PROMPT-010 e PROMPT-011).
